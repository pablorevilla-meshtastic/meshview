# Покрытие

## Прогноз покрытия

Meshview может показывать границу прогнозируемого покрытия узла. Это оценка
**модели**, а не гарантия реальной работы.

### Как это работает

Граница покрытия рассчитывается с помощью модели распространения Longley-Rice / ITM в
**зональном режиме** (area mode). Зональный режим оценивает средние потери на трассе
над типовой местностью и не использует профиль рельефа. Поэтому он учитывает общее
влияние расстояния, но **не** учитывает тени от рельефа, здания и растительность.

### Что вы видите

Интерфейс рисует **периметр** (а не тепловую карту) — наибольшее расстояние, на
котором прогнозируемый уровень сигнала выше порога (по умолчанию `-120 dBm`). Модель
рассчитывается по нескольким направлениям от узла, и последняя точка выше порога в
каждом направлении образует контур.

### Основные параметры

- **Частота**: по умолчанию `907 MHz`
- **Мощность передатчика**: по умолчанию `20 dBm`
- **Высота антенн**: по умолчанию `5 m` (TX) и `1.5 m` (RX)
- **Надёжность**: по умолчанию `0.5` (медиана)
- **Неровность рельефа**: по умолчанию `90 m` (средний рельеф)

### Требования

Модели нужен необязательный пакет `pyitm`. Он входит в `requirements.txt`, а при
установке из пакета его можно добавить через дополнение `coverage`
(`pip install 'meshview[coverage]'`). Без него кнопка покрытия сообщает, что прогноз
покрытия на сервере недоступен.

### Ограничения

- Данные о рельефе и зданиях не используются (только зональный режим).
- Результаты сильно зависят от мощности, высоты и порога.
- Условия окружающей среды могут сильно отличать реальность от прогноза.
